Responsive Food Delivery Landing Page
Responsive Food Delivery Landing Page
Project Overview :-The project is a responsive food delivery services website. The website is built using HTML and CSS. It includes a logo with banner, how it works section, city with locations, customer testimonials, pricing plans and a footer with copyright section.
I have used HTML, CSS, CSS Grid, CSS Flexbox and Media Queries.

How to Run the Project :-
1.	Open the Project Folder
2.	Go to index.html 
3.	Open index.html in any browser.
Responsive Design
For Desktop – Above 1200px -> Full gris layout is displayed.
For Tablet  - Below 834px – >Layout changes two columns.
For Mobile – Below 390px ->Layout changes to a single column.
